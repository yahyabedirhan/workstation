# herdr

Terminal multiplexer built for coding agents. Keeps sessions alive on a remote machine and shows each agent's state (working, blocked, done) in a sidebar.

- [config.toml](config.toml) - copy of `~/.config/herdr/config.toml`
- [cheatsheet.md](cheatsheet.md) - terminology, keybindings, detach vs close vs kill
- [setup.md](setup.md) - install, Claude Code integration, remote attach

Docs: https://herdr.dev, agent guide: https://herdr.dev/agent-guide.md
